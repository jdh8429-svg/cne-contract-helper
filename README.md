# 충청남도교육청 계약 업무 도우미

나라장터(조달청) OpenAPI 3종과 법제처 조달청 법령해석 API를 한 화면에서 쓰는 업무용 웹사이트입니다.
Cloudflare Pages(무료)에서 동작하며, 인증키는 Cloudflare 환경변수에만 저장되어 브라우저에 노출되지 않습니다.

## 메뉴

| 메뉴 | 내용 | 사용하는 API |
|---|---|---|
| 계약 관리 | 업무별(물품·공사·용역·외자) 계약 조회, 계약 상세·업체, 공고→계약 흐름, 계약 변경이력, 우리 기관 최근 계약 | 계약정보서비스, 입찰공고정보서비스 |
| 업체 확인 | 사업자번호로 업체 기본정보·등록업종·공급물품·**부정당제재** 확인 | 사용자정보서비스 |
| 유사사업 찾기 | 공고명 키워드로 전국 유사 공고 검색, 제안요청서·과업지시서 등 첨부문서, 추정가격 통계, 계약 결과 | 입찰공고정보서비스, 계약정보서비스 |
| 공고 준비 · 확인 | 우리 기관 공고 현황, 면허제한·참가지역·기초금액·정정이력·e발주 문서 | 입찰공고정보서비스 |
| 법령 · 해석 찾기 | 조달청 법령해석 검색, 질의요지·회답·이유·관련법령, 원문 보기 | 법제처 ppsCgmExpc |
| 내 보관함 | 계약·공고·업체·해석 저장, 메모, CSV 내보내기 (브라우저별 저장) | - |
| 설정 | 기관명·기관 기준·주요 업무, 인증키 연결 상태와 연결 테스트 | - |

## 구조

```
public/            화면 (index.html, style.css, app.js)
functions/api/     Cloudflare Pages Functions (서버)
  g2b.js           나라장터 API 프록시 – 허용된 오퍼레이션만 호출, 10분 캐시
  law.js           법제처 API 프록시 – OC 값 숨김, 30분 캐시
  health.js        인증키 설정 여부 확인 (값은 내보내지 않음)
test/              로컬 테스트
```

## Cloudflare Pages 배포

1. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Pages** 탭 → **Connect to Git**
2. 저장소 `cne-contract-helper` 선택 → **Begin setup**
3. 빌드 설정
   - Framework preset: **None**
   - Build command: *(비워 둠)*
   - Build output directory: **public**
4. **Environment variables (advanced)** 에 아래 두 개를 추가하고 **Encrypt**(암호화)를 켭니다.

   | 이름 | 값 |
   |---|---|
   | `G2B_SERVICE_KEY` | 공공데이터포털 인증키 (Decoding 키 권장, Encoding 키도 동작) |
   | `LAW_OC` | 법제처 Open API OC 값 (아이디) |

5. **Save and Deploy** → 배포가 끝나면 `https://<프로젝트명>.pages.dev` 주소가 생깁니다.
6. 사이트의 **설정 → 실제 조회로 연결 테스트**로 4개 API가 모두 '정상'인지 확인합니다.

> 배포 후 환경변수를 바꿨다면 **Deployments → 최신 배포 → Retry deployment** 를 눌러야 반영됩니다.

## 문제 해결

- **"등록되지 않은 인증키"** – 공공데이터포털 승인 직후에는 1~2시간 반영이 늦을 수 있습니다. 키 앞뒤 공백도 확인하세요.
- **"활용신청이 승인되지 않았습니다"** – 입찰공고·계약·사용자정보 3개 서비스를 각각 활용신청했는지 확인하세요.
- **법제처 "인증에 실패"** – 법제처 OPEN API 신청서에 등록한 도메인/IP를 확인하세요. Cloudflare는 고정 IP가 아니므로 도메인(`<프로젝트명>.pages.dev`)으로 등록하거나 법제처에 문의가 필요할 수 있습니다.
- **"입력값 범위를 초과"** – 조회 기간을 1개월 이내로 줄여 보세요.
- 개발계정은 서비스별 하루 1,000건 한도입니다. 같은 조회는 10분간 캐시되어 호출 수를 줄입니다.
